# Sonar: The Last Sense

Top-down survival game. Collect coins, manage health kits, and avoid monsters in a derelict lab.

## Controls

| Action | Keys |
|--------|------|
| Move | WASD / Arrow keys |
| Use health kit | E or H |
| Restart | R |

## Features

- Coin collection (+10 score each)
- Health bar with damage from monster contact
- Health kit pickups (press E to heal)
- Persistent high score (`user://sonar_save.cfg`)
- Chasing monsters using the included monster spritesheet

## Run

Open the project in Godot 4.7+ and press Play (`F5`). Main scene: `scenes/game.tscn`.
